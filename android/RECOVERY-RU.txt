TimeLineStamp — перенос на другой Android

Этот комплект содержит программу, опубликованные метки и хеши, настройки источников
и (если добавлены при сборке) APK Termux и Termux:Boot. Интернет нужен для установки
Python и получения свежей истории. Токен GitHub и SSH-ключи в комплект не входят.
Старые сырые измерения восстанавливаются только из отдельной копии SQLite.

1. Остановите старый сборщик. Если телефон потерян, отзовите его GitHub-токен.
   На двух телефонах одновременно публиковать результаты нельзя.
2. Установите APK из apps/ (Termux и Termux:Boot должны быть из одного источника).
   Для комплектных APK нужен Android 7 или новее. Если APK не приложены, ссылки
   на официальные варианты есть в RECOVERY.md. Не смешивайте подписи приложений.
3. Откройте Termux, выполните termux-setup-storage и разрешите доступ к файлам.
   Откройте Termux:Boot один раз. Для обоих приложений включите автозапуск
   и режим батареи «Нет ограничений» в настройках Android.
4. Распакуйте весь ZIP в Download. В Termux выполните:

   sh ~/storage/downloads/TimeLineStamp-recovery/project/android/recover-on-phone.sh

   Если сохранилась полная резервная копия, передайте её вторым аргументом команды:

   sh ~/storage/downloads/TimeLineStamp-recovery/project/android/recover-on-phone.sh ~/storage/downloads/timelinestamp-YYYY-MM-DD.sqlite3.gz

   Скрипт сам получает свежую историю из GitHub. При ошибке сети он останавливается.
   Существующую базу не перезаписывает. Опубликованные записи не пересчитывает.
5. Для публикации создайте новый ограниченный токен Contents: read/write только
   для RIFT-Experimental-Lab/TimeLineStamp под аккаунтом AntonKreighoff. Затем:

   bash ~/TimeLineStamp/android/configure-publishing.sh

   Вставьте токен в скрытый терминальный ввод. Не отправляйте его в чат.
6. Проверьте состояние:

   python ~/TimeLineStamp/timelinestamp.py --status
   python ~/TimeLineStamp/probe_v2_sources.py --require-termux --enabled-only

   Восстановленные даты и метки должны совпасть с Git. На новой сети источники
   проверяются заново. Не меняйте набор источников уже опубликованных суток.
7. Запустите сборщик:

   sh ~/.termux/boot/90-timelinestamp

   Скрипт остаётся работать. Первые новые полные сутки начинаются со следующей
   полуночи UTC. Перерыв после старого телефона останется пропуском.
8. Для публичного скачивания архивов запустите в другой сессии Termux:

   sh ~/TimeLineStamp/android/enable-downloads.sh

   Адрес Quick Tunnel публикуется автоматически только после проверки связи.
   Без подключения GitHub-токена кнопка на сайте не сможет узнать новый адрес.
   Quick Tunnel — экспериментальная услуга без гарантии доступности.
9. Перезагрузите телефон и проверьте, что процессы восстановились. При наличии
   блокировки Android может требовать первую разблокировку после перезагрузки.
   SSH на новой мобиле настраивается отдельно (ANDROID.md).

Архив выдаётся как снимок сохранённых данных за закрытые сутки. Теневые данные
могут приходить позже и менять версию архива, не меняя закрытый суточный хеш.
Скачивание не даёт доступа к управлению сборщиком или к конфигурации.
